# Security Policy

## Supported Versions

Security updates and patches are actively applied to the current major release (`2.x`) of LeveloJS. Earlier major versions (`1.x` and below) are no longer maintained.

| Version | Supported          |
| ------- | ------------------ |
| 2.2.x   | :white_check_mark: |
| 2.0.x – 2.1.x | :x:          |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately via GitHub's **Private Vulnerability Reporting** feature on this repository (under the **Security** tab -> **Advisories** -> **Report a vulnerability**).

When submitting a report, please include:

- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal reproduction repository.
- Any affected packages (`levelojs`, `levelo-cli`, `vite-plugin-levelojs`, `create-levelo-app`, or `levelo-windows`).

You can expect an initial acknowledgment within **48 hours**, followed by updates as we investigate and prepare a patch.
