# levelo-windows

Official Windows native runtime and renderer backend for **LeveloJS** applications.

> **⚠️ Early Beta / Pre-Release Notice**
>
> `levelo-windows` is currently in active early development and has **not** reached its public MVP release yet.
>
> **Please do not add or use this crate in any project yet.** APIs, windowing primitives, and rendering internals are still under active construction and subject to breaking changes without notice.

## Status

- **Stage:** Pre-MVP / Early Development
- **Purpose of this release:** Crate name reservation and internal testing
- **Stability:** Experimental — not intended for general or production use

## Ecosystem

- **levelojs** — Core fine-grained reactive UI framework
- **levelo-cli** — Official CLI and bundler _(pre-release)_
- **vite-plugin-levelojs** — Official Vite integration plugin
